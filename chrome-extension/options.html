Getting started after install

This extension is a remote control. It needs the Tail MCP server running somewhere it can reach (your machine, a LAN box, or a small VPS) before it can do anything.

  1. Get the server 
    git clone https://github.com/rtf6x/tail-browser-mcp
cd tail-browser-mcp
  2. Start MCP server 
    npm run docker:up
  3. Set browserId Scroll to Browser ID below — unique per install (e.g. browser-chrome).
  4. WebSocket URL Default ws://127.0.0.1:18789 for a local server. Use wss://… for cloud or LAN hosts.
  5. Connect OpenCode One MCP entry: http://127.0.0.1:18790/mcp. Use list-connected-browsers to discover IDs; pass browserId in other tools when multiple browsers are connected.
  6. Page access Per-domain approval when the AI first reads or scripts a site.
Multi-browser setup (GitHub)

Browser ID

Unique ID for this browser install. The MCP server routes tool calls by browserId. Letters, digits, _, - only (1–64 chars). Spaces are converted to -.

WebSocket URLs

Full WebSocket URL(s) of the MCP server — one per line or comma-separated. Local default: ws://127.0.0.1:18789. Remote/cloud: wss://your-host:port. Saving a non-localhost URL prompts for host permission.

Site Access

By default, page reading and scripting require approval per domain. Enable access to all sites to skip per-domain prompts (the domain deny list still applies).

Access all sites
Same as choosing “On all sites” in chrome://extensions for this extension.
